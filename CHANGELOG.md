## 2026-10-28 (Profile Backup and Cross-Browser Restore)

- The profile-management page adds “Export all profiles,” which downloads a JSON backup containing all child profiles, the currently selected child, and diagnostic history for every subject. The backup preserves original IDs and fields such as timestamps, and includes a format version and export time.
- Adds “Import backup file”: validates the file and displays a preview; after confirmation, merges by child ID and record key. Existing profiles are retained, different IDs with the same name are renamed automatically, duplicate records keep the newer result, and importing the same file again does not create duplicates.
- Merged history is no longer truncated at 40 entries. Import stops for files with more than 8 children, corrupted files, or unsupported versions. An expired preview requires confirmation again; if storage fails, the importer attempts to restore the original records.
- Export is disabled when there are no profiles; read or parse failures display an error. The file is processed in the browser and profiles are not uploaded.
- Dependency-free test `node tests/test_children.js` covers export, restore, merge, conflicts, duplicate imports, and storage failures; format and scope are documented in `docs/pwa.md`.
- Adds `node tests/test_children_browser.js`, which uses a temporary browser and isolated storage to verify actual file download and selection, cross-browser restore, history display, and the merge flow.

### Diagnostic Utility

- **At most 2 questions per knowledge point**: a correct first answer → mastered (and ancestors inferred as mastered, as before); a wrong/“don't know” first answer → another question at the same or an easier level (basic preferred, then same difficulty). A second wrong answer → weak and trace prerequisites (hard before soft); a second correct answer → **shaky** (shown separately on the result page and included in the learning path; **prerequisite tracing is off by default**, as documented in README). If a point has only 1 question, a wrong first answer immediately marks it weak.
- The question limit counts questions, default **16** (adjustable from 8–30 in settings; URL `limit=` still works). A point for which only the first question was answered incorrectly when the limit is reached is temporarily treated as weak and marked “not retested.”
- Question selection: seedable pseudorandomness (mulberry32; each random value depends only on the seed, knowledge point, and question number, so a session can be replayed). URL `seed=` fixes the seed (demo mode defaults to `demo`). localStorage records question IDs already asked (`cnmDiagnose.seen.v1`); retests prefer questions not asked before.
- After each answer, displays the **reference answer and explanation** (including for automatically graded questions; “don't know” also displays them before continuing), then the user selects “Next question.” Multiple-choice questions are answered by selecting an option.
- Grading depends on question type: multiple choice compares letters (option text is also accepted); numeric checks value equivalence (`unordered` controls whether multiple answers may appear in any order); short-answer normalizes and matches exactly, then checks `accept`, otherwise asks for self-assessment; self-assessed questions always use self-assessment; without a question bank, falls back to the old general grader.
- Result pages add “shaky” statistics and grouping. Answer history shows the question, your answer, and reference answer. Exported JSON is upgraded to version 2 and includes each question's ID, stem, your answer, result, reference answer, explanation, and `shaky`.
- Demo mode (`demo=1`) simulates: the target as weak, its prerequisites as weak, one point further back as shaky, and all others as mastered; the result page shows mastered / shaky / weak.
- Engine adds `nextItem` / `pickQuestion` / `judgeQuestion` / `questionById` and `buildGraph(topics, deps, questions?)`; sessions add `attempts`, `seed`, and `avoid`; save key is upgraded to v2 (old saves are no longer read).
